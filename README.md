# 🩺 Sajha Doctor – Doctor Appointment Booking System (MERN Stack)

Sajha Doctor is a full-stack web application built using the **MERN Stack** that allows users to easily book doctor appointments online.  
The platform connects **patients and doctors** in a simple, fast, and accessible way, reducing long hospital queues and improving healthcare accessibility in Nepal.

---

## 🚀 Features

### 👨‍⚕️ For Patients
- User registration & login (JWT authentication)
- Search doctors by specialization
- View doctor profiles & availability
- Book appointments online
- View appointment history
- Cancel appointments

### 🏥 For Doctors
- Doctor registration & login
- Manage available time slots
- View upcoming appointments
- Accept / reject appointments
- Profile management

### 🛠️ Admin Panel
- Manage doctors & patients
- Approve or reject doctor accounts
- View all appointments
- Dashboard with statistics
